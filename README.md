# Static Noise for VS Code

Static Noise is a dark Visual Studio Code theme generated by [static-noise](https://github.com/hcastillaq/static-noise).

## Install manually

1. Obtain a `static-noise-*.vsix` file from the maintainer.
2. In VS Code, open the Extensions view.
3. Select **…** → **Install from VSIX…** and choose the file.
4. Open **Preferences: Color Theme** and select **Static Noise**.

The extension is not published to Visual Studio Marketplace or Open VSX.

## Update

Install a newer VSIX with a higher extension version using the same **Install from VSIX…** flow, then select Static Noise again if needed.

## Build a VSIX

```sh
npm install
npm run package
```

The package is written to `dist/`. The theme JSON is vendored from the immutable upstream commit documented in [UPSTREAM.md](UPSTREAM.md); this repository does not regenerate the palette or theme.

## Maintainer synchronization

Theme updates are synchronized from a tagged Static Noise release by GitHub Actions. The workflow opens a PR using the upstream version and immutable commit SHA; maintainers do not copy theme JSON manually.
